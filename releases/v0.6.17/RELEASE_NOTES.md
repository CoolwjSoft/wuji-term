# WujiTerm v0.6.17

## 新增功能：手机扫码远程控制桌面终端
- **扫码即连 Mobile Web 终端**：桌面端内置离线可用的 Axum HTTP + WebSocket 服务（`xterm.js` + 手机快捷控制栏 + 代码片段抽屉），手机扫码即可实时接管或协同控制桌面终端会话，支持 128 KB 历史输出回放与实时终端流同步。
- **高危命令安全护栏联动**：手机端输入的命令同样经过桌面端高危命令护栏（`guardrail`）检测拦截。
- **公网无端口映射穿透（WebSocket Relay）**：`wuji-sync-server` 新增 `/api/v1/relay/host` 中继能力，支持 4G/5G 公网环境下免端口转发远程控制。

## 今日其他优化
- **备忘录工作台（Memo Studio）优化**：完善编辑/预览交互、图片管理、多格式排版与分类检索。
- **Windows 工作台优化**：同步优化窗口交互与稳定性。
