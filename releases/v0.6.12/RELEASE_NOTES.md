# WujiTerm v0.6.12

## 自动更新体验全面升级
- **4 档更新检查策略**：新增「不检查更新」「仅检查提示」「检查并下载（默认）」「自动下载并升级」，并修复手动点击「立即检查更新」及切换策略后未立即触发下载/升级的问题。
- **延迟与定时后台检查**：改为应用启动 3 分钟后首次静默检查，之后每隔 4 小时自动检查一次，零轮询开销，不影响启动速度与日常使用。
- **下载实时进度条**：更新包采用流式分块下载，界面实时展示下载进度条、已下载/总大小与百分比。
- **Markdown 更新说明**：版本新增功能说明升级为 Markdown 富文本渲染（支持标题、列表、粗体、行内代码、代码块、引用与表格），并过滤校验哈希等冗余信息，仅展示更新内容。
- **顶栏一键重启切换**：自动升级就绪后，右上角提示徽标自动切换为「重启切换新版本」，点击即可直接重启生效。

## 平台与 AI 能力增强
- **Linux ARM64 (`aarch64`) 支持**：新增 Linux ARM64 桌面端、CLI 与同步服务端构建及全平台自动更新支持。
- **安全锁与本地大模型目录**：新增应用安全锁功能，并支持云端本地大模型清单同步与多系列动态模型目录。
