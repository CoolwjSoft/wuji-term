# WujiTerm v0.6.14

## 新增功能
- **工作台备忘录（Memo Studio）**：新增支持 Markdown 与富文本的备忘录工作台，支持图片粘贴/管理、分类检索与命令面板快捷入口。

## 今日全部更新汇总
- **4 档更新检查策略**：支持「不检查更新」「仅检查提示」「检查并下载（默认）」「自动下载并升级」。
- **延迟与定时后台检查**：启动 3 分钟后首次静默检查，之后每隔 4 小时自动检查一次，零轮询开销。
- **下载实时进度条**：流式分块下载，实时展示进度条、已下载/总大小与百分比。
- **Markdown 更新说明**：富文本渲染更新内容，自动过滤校验哈希等冗余信息。
- **顶栏一键重启切换**：自动升级就绪后，右上角提示自动切换为「重启切换新版本」。
- **快速新建本地终端优化**：支持将快捷启动参数转发至运行中的单实例并自动取消最小化唤起主窗口。
